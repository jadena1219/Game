# Knight's Last Stand

A 2D mobile melee wave-survival game. Ten waves, one knight, no retreat. Built
with plain HTML5 Canvas + JavaScript — runs in any phone browser, no install.

## Play

It uses ES modules, so it must be served over HTTP (not opened as a `file://`).

```bash
npm start          # serves at http://localhost:8080
# or: node tools/serve.js 8080
```

Open the URL on your phone (same Wi-Fi, use your computer's LAN IP) or in a
desktop browser.

## How to play

- **Move:** left side of the screen — touch and drag a virtual joystick. The
  knight faces the way he moves.
- **Swing:** the glowing button on the bottom-right swings the greatsword in a
  wide ~120° arc in front of you, hitting every foe in the cone. It also
  deflects incoming projectiles.
- **Desktop testing:** `WASD` / arrow keys to move, `Space` / `J` to swing.

## Rules

- **10 levels = 10 waves.** Each level spawns a fixed number of foes; clear them
  all to advance. **Level 5** is the Dark Knight mini-boss, **Level 10** is the
  Demon Lord.
- **Max HP is fixed** (100) and never grows. Clearing a level restores **+30 HP**
  (capped at max).
- **If your HP runs out you restart from Level 1.** It's one continuous run —
  reaching the Demon Lord is earned.
- Enemies get tougher each level (more of them, more HP, faster, new types):
  **skeletons** (chasers), **imps** (fast swarmers), **dark mages** (ranged
  casters), and **ogres** (tanks).

## Project layout

```
index.html            # shell + menu overlays
css/style.css         # styling
js/
  main.js             # bootstrap + menu wiring
  game.js             # state machine, waves, collisions, rendering, HUD
  entities.js         # player, enemies (AI), projectiles
  config.js           # all balance/tuning + level composition
  input.js            # touch joystick + swing button, keyboard fallback
  sprite.js           # sprite animation/drawing helper
  assets.js           # sprite manifest + image loader
assets/sprites/       # generated pixel-art humanoid sprite sheets (PNG)
tools/
  gen-sprites.js      # parametric humanoid sprite generator
  png.js              # dependency-free PNG encoder
  serve.js            # tiny static file server
```

## Sprites

All characters are real pixel-art **humanoid** sprites (16×24, 4 frames each:
idle, two walk frames, attack), generated by `tools/gen-sprites.js`. Re-generate
with:

```bash
npm run sprites
```

Tuning (HP, damage, speeds, level composition) all lives in `js/config.js`.
